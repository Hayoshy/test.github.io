Сюда кладутся картинки меток для категорий.

Имя файла = id категории из Supabase:  1.png, 2.png, 3.png ...
(можно .svg или .webp). Список id и названий — на странице markers-guide.html.

Требования к картинке:
  * PNG или SVG с прозрачным фоном;
  * примерно 88 x 104 px (в 2 раза больше размера на карте 44 x 52) или любая
    с похожей пропорцией — она сама впишется;
  * острый «носик» метки должен быть внизу по центру: он указывает на точку;
  * в правом верхнем углу сайт сам рисует цветной кружок статуса
    (красный — не решена, жёлтый — решается, зелёный — решена), поэтому
    оставьте этот угол свободным.

Если файла для категории нет, на карте будет обычная цветная метка.
После замены файлов обновите страницу сочетанием Ctrl+F5.
