Картинки меток для категорий

Положите файл в папку img/markers/ и назовите его по id категории, например 1.png. Подойдут PNG, SVG и WEBP с прозрачным фоном, около 88 × 104 px; острый конец метки должен быть внизу по центру, а правый верхний угол остаться свободным: туда сайт ставит цветной кружок статуса.

Откройте страницу через Live Server, чтобы проверить, какие файлы уже найдены.
