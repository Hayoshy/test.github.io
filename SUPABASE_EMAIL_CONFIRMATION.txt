НАСТРОЙКА EMAIL CONFIRMATION В SUPABASE

1. Supabase Dashboard → Authentication → URL Configuration.
2. Site URL установите в адрес опубликованного сайта, например:
   https://kartaproblemgoroda.github.io
   (если фактический адрес сайта отличается, используйте фактический).
3. В Redirect URLs добавьте:
   https://kartaproblemgoroda.github.io/auth-callback.html
   и, если используете локальный сервер для тестирования:
   http://localhost:5500/auth-callback.html
4. Authentication → Providers → Email: включите Confirm email.
5. Для надёжной отправки писем настройте SMTP в Authentication → SMTP Settings.

После регистрации письмо ведёт на auth-callback.html. Эта страница обменивает
код подтверждения на сессию и перенаправляет пользователя на index.html.

Если сайт размещён не в корне kartaproblemgoroda.github.io, замените URL выше
на фактический URL публикации. Старое письмо, отправленное до исправления,
может вести на прежний адрес: зарегистрируйте тестовый адрес заново или
запросите новое письмо подтверждения.
