НАСТРОЙКА ПОДТВЕРЖДЕНИЯ ПОЧТЫ

1. Supabase Dashboard → Authentication → Providers → Email.
2. Убедитесь, что Email provider включён.
3. Включите Confirm email / Email confirmations.
4. Authentication → URL Configuration:
   - Site URL: адрес опубликованного сайта.
   - Redirect URLs: добавьте точный адрес сайта и адрес index.html.
5. Сохраните изменения.

При регистрации сайт отправляет письмо на указанный пользователем адрес.
Пользователь должен открыть письмо и нажать ссылку подтверждения.
После подтверждения он возвращается на index.html и входит с почтой и паролем.

ВАЖНО:
- Для отправки писем в рабочем проекте настройте SMTP в Supabase Auth → SMTP Settings.
- Не отключайте подтверждение email, если хотите требовать подтверждённую почту.
- Не публикуйте Secret API Key или service_role key.
